# TypeScript Generics

## What I wanted to understand

How to initialize a project, and easily execute a tscript code.

## What I discovered

- Npm install -g typescript 
- tsc -> for compiling every TS file under the directory to the JS equivalent 
- tsc --init -> For initiliazing the typescript configuration
    - module and tarjet: commonjs, ES2026...etc
    - noEmitOnError: Don't execute if error
    - rootDir and outDir: Where the src and dist folders will be.
    - sourceMap: Mapping from ts to js.
